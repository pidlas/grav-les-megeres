<h2>Hébergement</h2>
<p>
Le site est hébergé chez Philippe Guerrini Idlas. Le serveur est un matériel Open Source doté d'un processeur anglais ARM
construit sur une carte hongroise de la société Olimex. Le serveur tourne sous armbian, une version Debian pour le processeur ARM.
La gestion internet est assurée par une solution Open Source, <a data-type="external" href="https://yunohost.org/#/" target="_blank"
rel="noopener noreferrer">YunoHost</a><span class="lien-e-seul"></span>. Le nom de domaine est géré par le registrar Gandi.
</p>
